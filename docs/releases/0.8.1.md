## What changed

### Desk (#441)

- **Every desk text box grows to fit its text.** A desk text box now grows as text is typed, pasted, or set by code, such as a Pull, a loaded draft or a reset. It shrinks back when text is removed. It is never shorter than its `rows` height, so an empty box is the size it is today. When it reaches 70% of the window height it stops growing and scrolls inside. The drag corner stays. The story editor's headline, dek and body keep their own sizing code, so they still have no 70% cap. The reader site does not change.

### Documentation (#440)

- **The lead-score drawing is in the diagram tool and the lists.** The manual has fourteen Mermaid blocks, but `docs/diagrams/render.sh` named only thirteen, so a render run stopped with a count error. The missing drawing, "How a lead gets its score", is added in its place as a Mermaid source and a rendered SVG, and the diagram lists in `README.md` and `docs/diagrams/README.md` name it.
