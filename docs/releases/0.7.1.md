## What changed

### Community resources (#429, #433, #434, #435)

- **Auto-grow and auto-publish (#429).** The daily scan pins every registry source. A registry source with no clean read in 7 days counts as registry-relevant even when its page did not change. Links on a directory page become accepted registry sources when they stay on the directory's own site or an official domain; search results, redirectors and social media are refused. New sources are capped at 25 a day and 2,000 in all. A change that names no existing entity creates the organization, service or location row; an ambiguous name is never duplicated. A change whose cited registry source page was captured in the same run is applied and published through the same path an editor's publish uses, with an audit row naming the source and the scan. Crisis services are published too, with a `[Crisis]` audit row, and the desk lists them first. `/desk/registry` has an **Auto-published** list with the source URL and an **Unpublish** button. Setup imports and publishes the Longmont directory file when it is present, once, and only for a Longmont paper. The desk's entry cards show every field, and each proposal shows its old and new values, the page's own sentence and the source.
- **Nightly recheck (#429).** Each night the scheduled scan reopens about a thirtieth of the published registry (cap 200), oldest recheck first; crisis services are due every 7 days and go first. It fetches the source page and compares its key facts through a model read. A changed entry is applied and published through the same autopublish path, with an audit row. A recheck never creates entities and never writes an editor's verification fields. A 404, 410 or DNS failure records one failure; a second gone recheck at least three days later unpublishes the entry and lists it under **Source gone**. A timeout or 500 changes nothing. `/registry/<id>` says `Last checked <date> — checked against <site>` when the robot's recheck is newer, and never calls a robot recheck "verified". The desk has a **Freshness** panel and a **Source gone** list.
- **The public page is redesigned (#435).** `/registry` uses the full page width, with a **911**, **988** and **2-1-1** row, one card per service with **Call** and **Directions**, category chips, and results that appear as you type. Everything the old page showed stays inside **All details, source and corrections**. On a phone the cards are one column and **Call** is a full-width button. The form still works with no JavaScript.
- **One name once (#433).** The desk and the public page show a registry name once when the organization and the service have the same name, and the desk draws one Auto-published card for each service.
- **The build ships the Longmont directory file (#434).** The build copies the file beside every built chunk that reads it, and fails if it cannot.

### Desk (#420, #421, #422, #424, #425, #427, #428, #430, #431)

- **Queue ticks (#420).** Kill, Hold and Delete untick the lead they move off the list. A lead the server refuses stays ticked. **Start N stories** still drafts every ticked lead, including those off screen.
- **Nine desk findings from the Nov 19 walk (#421).** "Read today" uses calendar days in the paper's Denver time zone. **Beat memory** opens its panel. An `hsds://` address shows as plain text. **Today** is current only on `/desk`. A past retry time reads **No retry scheduled.** A **Not ready** draft appears in **Needs you**. **Publish all drafts**, **Publish N selected** and **Run scan now** ask first. Health **Errors in 24 h** counts failed desk jobs and follow-up checks that ended `could-not-check`.
- **Plain words and kept focus (#422).** A bulk Kill or Hold says how many leads failed, and Kill asks **Kill N leads?** first. A message that is not an editor sentence becomes **The server did not accept that. Try again.**, with the raw value in the console. Focus moves to a confirm's safe button when it opens and back to the trigger when it closes. **S** asks before it starts a story.
- **A lead cites the story's own page (#424).** Filing adds the one article link on a home or list page whose text plainly matches the headline, before the list URL. No clear match adds nothing. The scan prompt asks for the story page. Old leads are not changed.
- **The research tool is found under any Node (#425).** The lookup checks a `nodejs*` folder under `%USERPROFILE%\scoop\persist` and beside an npm `claude.cmd` shim. Health shows a red row when the CLI is missing and the research writer is on the drafting ladder.
- **Alike counts are labeled (#427).** Notes explain the Queue tabs, lead matches against one story, Health's draft records, Suggested links against sites, the source picks and fetch cap, and the 30-minute arrivals window. No count's meaning changed.
- **The Health research row fits its card (#437).** The red **Research tool not found on this computer** line on `/desk/ops` wrapped nowhere and ran 75 px past the Health card at 1440 px. It now wraps inside the card.
- **Redraft words (#428).** The dialog now says the new version replaces the story text, and the Keep card says **My headline**.
- **Capture with Firecrawl Local (#430).** An opt-in button on each active watch takes one capture through a local Firecrawl service at `127.0.0.1:18764`. It does not move the watch baseline and saves nothing if it fails. There is no cloud fallback.
- **Send to Desk for Reddit (#431).** A Chrome button reads the open Reddit tab and puts the posts in a review list on the Dark Desk. Nothing files until the editor ticks posts and presses File.

### Public pages and readers (#423, #426, #432)

- **An out-of-state story is not Nearby (#423).** "Superior Court" no longer counts as the town of Superior, and an out-of-state story gets neither Nearby nor the county by default. The Queue and the story page show **This story may be about another state, not Colorado**. Stories already filed keep their area.
- **Five public-page findings (#426).** Geography pills are current only for their own filter. Explore menu labels wrap at phone width, and Escape closes the menu. Registry phone numbers are `tel:` links. An empty registry search shows the 988 and 211 crisis line.
- **A source with no title (#432).** A missing or non-string stored title gets a site label instead of breaking the story page.
