## What changed

### Global informational-text floor

TownReporter now enforces a global 14px floor for informational user-interface text. The root remaps `.text-xs`, `.text-[11px]`, and `.text-[12px]` through `calc(0.875rem * var(--ts, 1))`, preserving the desk's Normal and Large text scaling while preventing informational text from rendering below 14px. A Chromium computed-font-size regression test covers 8 routes, including a runtime-resolved real article route from `/sitemap.xml`; the article route is part of the default set and fails rather than silently skipping. This closes a GauntletGate Critical.

### Release-state correction and guard

The v0.6.54 documentation now states its actual published state: the tag, Windows asset, source commit, and publication timestamp are recorded, and the applied-migrations statement is corrected against the real production ledger. A new release-state test guards the current release note and the current-release statements in README, TODO, and the Windows guide against pre-publication wording once a release is published.

### Non-destructive authenticated desk regression

A new authenticated desk regression walks Queue, Scan, Sources, Published, Stats, and Server. It records before/after side-effect counts so the walk proves it did not mutate the desk. The `DESK_PRODREG_BREAK_SURFACE` hook provides a real red baseline, and a dedicated CI job uploads the regression evidence. The job is staging-only: it uses PGlite in CI, never production credentials, and never port 3000. The ephemeral PGlite CI path cannot exercise the real-count comparison; that comparison is only meaningful against an environment with persistent production-shaped counts.
