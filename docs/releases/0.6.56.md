## What changed

### Corrected self-referential hash publishing

v0.6.55 shipped a package whose internal release note stated the ZIP's own SHA-256 by value. Writing that value into the package changes the ZIP, so the note could never remain a fixed point. v0.6.56 changes the rule: the package-internal note does not state its own hash by value. It points to the adjacent `.sha256` sidecar as the hash authority.

### Release-sealed hash guard

A new release-hash guard verifies that the package-internal note references the `.sha256` sidecar, that the sidecar's value equals the actual ZIP hash, and that the note does not embed a self-referential SHA-256 value. The guard was demonstrated red against the v0.6.55 package before the v0.6.56 fix, then green against v0.6.56.
