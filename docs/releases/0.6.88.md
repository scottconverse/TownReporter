## What changed

### Reader pages and events

- The ICS reader reads ordinary and repeating events. Four more readers read WordPress, Squarespace, LibCal and CivicPlus event feeds. One source limit setting replaces the 12/13 caps (#349, #350).
- `routine_events` (migration 0159, additive) stores one row per source, event and day. The front page has an events week box: TODAY plus 6 days, Longmont then Nearby (#351, #352).
- 37 event feeds are in a seed list. The seed step runs as a dry run first and uses `--apply` to write (#353).
- The events box uses at least 14px text and 44px title links on a phone (#354).
- The Bulletin redesign changes reader pages: fonts, colors, masthead, nav, footer, dialogs, front page, story page, lists, standing pages and events data. The desk does not change (#357).

### Phone app install

- Readers can add TownReporter to the home screen on Android and iPhone. The manifest has 192, 512 and maskable 512 icons. `public/sw.js` caches nothing and shows **You are offline.** when the phone is offline (#383).

### Community resources (registry)

- Community Navigator Phase 1 adds registry tables (migration 0160, additive), HSDS import, a read-only `/desk/registry` and a public `/registry` (#376).
- Readers get a **Community resources** link and a public list. The editor can load 11 starter entries and publish each entry (#378).
- The editor can edit, add and take down entries. Each write is one transaction. Nothing is deleted (#379).

### Desk, Drafts and roundups

- A same-day routine re-run posts one short update note and updates the story list, dek and source links (#355).
- The scan ModelPicker moves below the header. The header keeps **Run scan now**, **Add a lead** and **+ New story** (#356).
- The Nov 2 bug list fixes roundups, dates, model ladder rows, OCR text, **Challenge this case**, Undo focus, job cards, warm-up, test seal, test limit and promote reload (#365).
- Drafts keeps published rows in view. J and U keys work on Undo. One-day dates row uses the real dek (#366, #367).
- A backlog batch fixes scan leads, desk text, status chips, sidebar space, source titles, past-run text, CLI timeout text and `/desk/scans` (#370).
- Solid dialog buttons, wider run rail, hex-id source titles and **Done** press are in (#371).
- Source card titles drop CDN file names. Story side panel text reaches 16px (#372).
- Desk body text, labels and buttons are 16px (#373).
- The **A person wrote this** line is removed. The default is **An outside AI tool** (#375).
- Opinion drafts show in **Opinion pieces waiting** on Drafts (#377).
- Waiting roundups have **Open / Close** and **Kill**. Rows draw full width, and long source addresses wrap on a phone (#380, #381, #382).

### Scan and leads

- The scan reads news links first, opens 6 extras and files leads during a hand-started scan (#358).
- A printed story carries its lead. A finder ref that says distinct or separate is omitted (#359).
- The scan warns when speech-to-text is missing (#364).

### Models and Ollama

- The watchdog can start Ollama when its shortcut has no arguments (#369).
- TownReporter looks after Ollama on 11435, warns when nothing answers and can run **Sign in to Ollama** (#374).
- Claude Fable uses label **Claude Fable 5.2** and model id `claude-fable-5-2` (#385).

### Operations and deploy

- `ops/deploy-production.ps1` no longer hangs. It waits for the promote process by PID (#360).
- `promote.ps1` reloads helper files after the fast-forward (#365).

### Tests and CI

- CI test fixes cover the scoped Claude Code switch, reader colors, Bulletin walks and the flaky fb6 test (#348, #361, #362, #368).
- Fast release checks add a scripted Publish walk, a changed-files runner and a scan replay (#363).

### Release check

- The #383 and #385 Test server walks passed with a real Publish. #383 went live on 2026-11-12 at 9:10 AM Mountain. #385 went live on 2026-11-12 at 11:19 AM Mountain. The live paper runs all 37 changes since 2026-11-12 at 11:19 AM Mountain (commit `ad4b6ad4`).
