# TownReporter 0.6.47

Release date: 2026-09-13. [GitHub release](https://github.com/scottconverse/TownReporter/releases/tag/v0.6.47) · [Windows installation](../windows-install.md) · [Reader guide](../reader.md) · [Editor desk](../editor-desk.md).

This patch makes the Editor’s desk a persistent part of the public reader header. The control remains labeled on desktop and phones, opens the existing desk for a signed-in editor, and follows the existing sign-in flow for a signed-out visitor. The footer newsroom links and every desk-to-public return path remain available.

The built candidate was checked against an isolated copy of the newsroom. The header control was verified at desktop width and at a 390-pixel phone viewport, with no horizontal overflow, and both routes opened the real editor workspace. This patch changes no database schema, editorial data, article address, model behavior or publishing workflow.

The tagged source, Windows package and live deployment are distinct artifacts. Deployment evidence records the exact production commit, served version, public response and retained published-story count.
