# TownReporter 0.6.48

Release date: 2026-09-14. [GitHub release](https://github.com/scottconverse/TownReporter/releases/tag/v0.6.48) · [Windows installation](../windows-install.md) · [Reader guide](../reader.md) · [Editor desk](../editor-desk.md).

This release repairs the Story workspace's local-model and evidence-review path. An explicit Local model choice uses the newsroom's discovered or saved OpenAI-compatible endpoint and selected model. The evidence check presents a persistent running state and saves a separate checked draft with the original and changed text available to the editor.

The final reporting pass now checks people’s names against retained written evidence. An exact official record can establish spelling only when its nearby text supports the same role, organization and locality. Uploaded written records can provide the same private receipt. Transcripts, captions, OCR text, ambiguous surnames and unsupported names do not certify themselves; they remain visibly marked for editor review.

If a factual draft arrives without a usable claims-and-sources ledger, TownReporter performs one bounded citation-only repair. Each accepted receipt must copy an exact fact from the finished draft, an exact supporting passage from a saved public capture and that capture's exact URL and stored identity. The application validates those fields independently. It does not attach every source the model opened. A failed or partial repair preserves the draft and labels it `Draft saved — review required`.

Writer checkpoints and final checked drafts now have separate durable IDs. The final completion receipt records citation status, evidence completion, name-check completion and the reasons an editor must review the result. Existing publication controls remain with the editor; this release adds an accurate warning rather than silently discarding a usable draft.
