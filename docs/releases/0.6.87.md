## What changed

### Dark Desk fixes from the October 28 walk

- **The stuck box waits for 150 seconds of quiet.** Long research steps send real progress, so **This round looks stuck** does not appear while work continues.
- **DeepSeek gets its own effort and time limit after a model switch.** When a round moves to DeepSeek after another model fails, it no longer inherits the failed model's 45-second limit.
- **The round card names the switch.** It shows **This round moved ...**. The waiting line names the new model, and a model timeout says the model did not answer.
- **Use selected model starts a new round on the picker's model.** It stops the current round and starts the new one. It also does this when the old round ends first.
- **PDF reads use the file's model.** If that model cannot read pages, the reader uses the automatic order and says so on screen.
- **Challenge the case records the model that ran.** If no model ran, the card says **No model ran**.

### Challenge the case with nothing new

With nothing new to check, **Challenge the case** finishes without a model call. Its card says **No model ran** and no longer names a model that did not run.

### Send to Dark Desk opens the new file

**Send to Dark Desk** opens the new file on the Dark Desk screen. It does not open an older file.

### Closed files and phone size

- On a closed file, the Decide panel says why **Keep investigating** is grey: **This file is closed. To open it again, use Pull back under More file actions.**
- **Close: no finding** shows **Already closed** on a closed file. No control was removed.
- On a phone at 640 px wide or less, Dark Desk buttons, selects, toggles and button links are at least 44 px tall, with text at least 14 px. The desktop layout did not change.

### Job cards stay current

- Each card's **Now:** line shows the worker's own words for the step. It no longer sticks on **Working on the case file**.
- The open-file list line **Reading · N of M records** updates every 3 seconds while a file is being investigated.
- **Retry on next model** names the model it will use, for example **Retry on next model (DeepSeek v4.1 Flash 1017)**. The named model is the model that runs.
- After the editor presses **Stop**, the card does not also show the wrong note that the app restarted.
