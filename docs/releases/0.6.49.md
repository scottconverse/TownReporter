# TownReporter 0.6.49

Release date: 2026-09-15. [GitHub release](https://github.com/scottconverse/TownReporter/releases/tag/v0.6.49) · [Windows installation](../windows-install.md) · [Reader guide](../reader.md) · [Editor desk](../editor-desk.md).

This release restores Dark Desk as a bounded lead-development system. It follows unresolved actors, money, beneficiaries, organizations and missing records while keeping both investigative and benign explanations visible. Each run has explicit time, model-call, search and document limits, checkpointed synthesis recovery, controlled frontier growth, live usage counters and honest stage reporting. Local Redlib can enrich Reddit results without replacing the independent RSS path.

Reporting-item **Pull** is now a durable mechanical research job. It shows its current search, provider and extraction stage, saves useful documents as it finds them, enforces a whole-run deadline, survives navigation and reloads, and supports Stop and Continue. Pull does not call a writing model or consume Claude, Codex or local-model tokens.

The editor can select Codex Astra, Sol, Terra or Luna and Claude Fable, Opus, Sonnet or Haiku as exact per-run models. Story, Scan and Dark Desk Automatic now try Codex Terra first and Claude Sonnet only after an eligible technical failure. Opinion Automatic uses Codex Sol first and Claude Sonnet last. Opus is never selected automatically. Explicit model choices do not fall back, and a content refusal stops the run.

Daily Scan and Queue batch drafting require one explicit named model. They offer all eight Codex and Claude choices, discovered Local models and saved Custom AI connections; they never use Automatic or provider fallback. Scanned PDFs and images now stay on the same model selected for the run, including Custom AI/Gemini connections, instead of entering a separate hidden OCR routing chain.

Story keeps model and research controls reachable during drafting and redrafting. Eligible quota, unavailable, authentication, timeout and network failures move unfinished work to the next Automatic provider while retaining uploaded documents and fetched research. The workbench identifies the provider switch instead of showing a dead request.

Queue batch drafting now accepts up to five eligible leads with one explicit Codex, Claude, Local or saved Custom AI runtime, including a Gemini OpenAI-compatible connection. Each lead retains its saved research scope. The batch pins the selected model, stores no API key or base URL in its job snapshot, creates editable drafts and never publishes.
