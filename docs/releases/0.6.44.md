# TownReporter 0.6.44

Release date: 2026-09-13. [GitHub release](https://github.com/scottconverse/TownReporter/releases/tag/v0.6.44) · [Windows installation](../windows-install.md) · [Current editor desk](../editor-desk.md) · [Changelog](../../CHANGELOG.md).

## What is included

This release packages the Astra editor desk and the reporting changes made since the 0.6.35 Windows package. Desk, Sources, Scan, Queue, Published, Opinion, Server and Stats retain their existing functions. Dark Desk and story workspaces use the same navigation. The TownReporter logo, breadcrumb and Public news page control return to the public paper.

Story and Opinion share document upload, extraction, OCR and section-by-section reading. Add or drop several files, paste long source text, or supply document, web and YouTube URLs. Failed Opinion requests retain saved material with a Restore saved material link. Document-based evidence checks use retained private text as well as web captures. Supported name corrections are applied from opened written evidence; unresolved identities stay marked for review.

Opinion defaults to Codex Sol. Automatic tries Claude Opus and can fall back to Sol; an explicit provider remains selected. Both subscription writers load the complete configured voice through native instruction-file options, with research tools available while writing. A refusal is a failed request, not a draft. A usable editorial without its required claims-and-sources appendix remains saved for repair and cannot be published as a completed checked editorial.

## Install or upgrade

Download the Windows ZIP from this release. Its SHA-256 file and JSON metadata identify the archive and exact source commit. Follow the installation guide; existing owners must use its upgrade procedure and preserve their private data and configuration. A GitHub source archive alone is different from the packaged Windows asset.

The release's verification receipt records the merged source commit, CI runs, published-asset installation result, and independently checked production deployment. These are separate checks: publishing a tag does not establish that a server runs it. GitHub Pages publishes the documentation from main/docs; it does not host the newsroom.

## Verification and limits

The native instruction-file change was exercised with the configured voice and a live Sol run that opened public sources. A separate complete Opinion run saved a recipe-preservation editorial, claims and sources, fact sheet and image prompt; the saved work reopened in the editor. That exercise did not publish an article. The release receipt records automated checks against the packaged source and downloaded release.

The earlier government-policy editorial refusal is not claimed resolved. Provider availability, quotas, refusals and tool availability remain provider behavior. A name marked for review has not been established by the available written evidence. OCR and captions can be wrong; neither certifies its own spelling. The selected-page PDF reader has a 12-page range limit, distinct from the multi-document intake. Full-packet reporting accuracy and the broader daily newsroom quality target remain editorial acceptance work.
