## What an editor can do now

### Import a finished report and check it story by story

`/desk/import` takes a finished report — the owner's own markdown or anything
else that arrives as text — and splits it into one card per story. Each card
carries the headline, the body, the section the chooser picked, and the sources
found in the copy. The editor ticks the cards to import, changes any section
first, and leaves the rest. A card that is not a story is offered as
"Not a story — import it anyway?" rather than being dropped silently.

### A report that states its own readiness is read the way it states it

A civic-scanner v2.6 report says, packet by packet, how far it got, and the
import takes that statement as the answer instead of guessing from the packet's
length. A packet the report calls ready arrives as a finished story, ticked. A
packet it calls developing arrives as a finished story, unticked, wearing
**Developing — gaps marked** with the gaps it admits to in its editor notes. A
packet it calls a possibility, anything under a **Black Desk** or **Possible
Stories to Investigate** heading, and every row of a held-and-potential table
arrive as story ideas, unticked, marked **Unverified — Black Desk**, and are
never a draft; each carries **Send it to Dark Desk**, which opens the Dark
Desk's start box with the lead, the report's label, its hypothesis and its own
next check already in it.

The claims ledger that came in with the report is kept as an editor note,
status by status, and is never published; a card whose ledger holds an
unverified or contested claim says so before the editor imports it. A run the
report calls PARTIAL is bannered above the cards, quoting the report's own list
of what remains. Pasting a full-pipeline report as JSON reads to the same
cards, and a paste that is not a report falls back to the plain reading.

### Paste one story

A single finished story can be pasted on its own and taken through the same
review screen, without a whole report around it.

### Add a source inside the section it belongs to

A source can be added from inside a section, so the new source lands in the
section being edited rather than in a general list.

### A section the chooser cannot place says so

When the deterministic chooser cannot place a story, the card arrives with
**Section not chosen — pick one** and an empty section, instead of a guess the
editor has to notice. The chooser is `topicFromText`, and it now reports
"unchosen" as a result of its own rather than returning a least-bad guess.

### The owner edits the named-outlet list on Server

The list of outlets the paper checks before printing is editable on the Server
page: the shipped list can be added to, removed from, and renamed. The panel
says what each state means as a fact about the paper, including the one state
that can only lose the paper a check — checking no outlet names at all — with
the warning that an editor can still add the source by hand.

### A save bar that says when a change is not saved

The outlet list and the other settings screens carry a bar that says a change
has not been saved yet and asks before leaving with unsaved changes.

### The paper's own front page as a river

The front page reads as a river: each item shows its section, headline, dek and
byline in one column, so the order the paper chose is visible in the shape of
the page.

### Meeting audio is transcribed through textflowkit, with the run recorded

Meeting audio is transcribed by textflowkit rather than by an in-process
transcriber, and the run's provenance is recorded. Imported leads record where
they came from as well.

### Which model runs when

Two different ladders are in play, and the desk states both:

| Surface                    | The order it walks                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------- |
| Stories, scans, Dark Desk  | DeepSeek v4.1 Flash → Qwen 3.6 35B **on this computer, when it is loaded** → Codex Terra          |
| Opinion                    | Codex Sol → Claude Sonnet                                                                          |

A named choice is still tried first. Claude Sonnet is on Opinion's ladder only;
it is a hand pick on the other surfaces. Opus is never selected by an
unattended ladder on any surface.

## What changed for safety

- **The input-check sweep is finished.** Publication, authentication and
  sign-in and sign-up, paper settings, and provider and model connections are
  validated, and the genuinely unbounded writes found in the sweep are bounded.
  A validator that returns its argument unchanged is a type annotation, not a
  runtime check, and those are what this replaces.
- **A publication refuses a named outlet the story does not credit**, unless an
  editor overrides that outlet for that draft, as 0.6.62 established.
- **A draft's section is confirmed by a person before it prints.**
- **Provider command-line children receive a named allow-list of environment
  variables**, not a copy of the server's environment.

Both lanes had claimed the same two migration numbers. The numbers now in the
tree, in the order the migrator applies them, are:

| File                                        | Adds                                                       |

| `0087_lead_topic_unchosen.sql`              | the lead topic's "not chosen" state                        |
| `0088_paper_settings_named_outlets.sql`     | the owner's named-outlet list on paper settings             |
| `0089_paper_settings_named_outlets_revision.sql` | the revision to that storage                          |
| `0090_textflowkit_provenance.sql`           | the textflowkit transcription run's provenance              |
| `0091_import_provenance.sql`                | `leads.origin`, `leads.provenance_json`, and the disclosure text on drafts and articles |

Only the textflowkit and import files were renumbered; their contents are
unchanged. Because the migrator keys its ledger by file basename, a duplicate
number would have caused the second file to be skipped in silence, so the
renumber was verified by applying `0087` through `0091` in order on an empty
database and on a copy of a database at `0086`.

## Known limits

- **Nothing in this release was run against a real AI model**, and no screenshot
  in the repository was taken against the live paper.
- **Production deployment is not asserted here.** A repository version, a tag,
  or a GitHub release does not establish what the live paper is running.
- **The named-outlet list can match a phrase rather than a masthead.** The words
  "times call" in ordinary prose can match "Times-Call", which refuses a story
  that should have printed; the editor's override is the way through.
- **The chooser is still deterministic and still not a classifier.** "Section
  not chosen — pick one" is an honest empty answer, not a better guess.
- **An imported report's claims ledger does not come back on the lead page.**
  The ledger is written into the imported lead's editor notes and is readable on
  the review screen before the import, but the lead page does not show it again:
  the lead page keeps the editorial assignment only for leads written in the
  write box or the story workspace, and an import writes a different origin
  (`src/lib/news/notes.ts:173-176`).
- **Meeting capture does not yet include a provisional-to-revision cycle
  observed against a real capture, and has no path from a transcript to a
  story.** Section 5 produces chunks, alignments and structured votes and
  deliberately does not draft.
- **Acceptance work remains open**: fresh-machine human acceptance of the
  Windows install; the live provider matrix; five useful Dark Desk outcomes plus
  the September 3–8 replay; and the post-crash detached-child limitation.
