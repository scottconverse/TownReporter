## What changed

### The Scan page finishes without a reload

The scanner already did its work, but an open Scan page could retain the old
running copy of a row when polling returned the same row ID with finished
values. The page now replaces an older copy with the newer row. A disposable
browser gate opens the page on a running row, finishes that exact row in the
database, and requires the busy state to clear without closing or reopening the
page. It does not contact a source or model.

### Meeting recordings now reach an editor safely

The meeting pipeline can file transcript evidence into the Queue, generate a
draft, and persist only the citations the draft actually used. The Story screen
shows those used citations separately from broader source material considered.

Transcript revisions are immutable: each caption and YouTube information
sidecar has a content-addressed path, verified hash, and historical database
record. Capture and publication share one PostgreSQL lock order. A draft tied
to an older recording, a missing link, malformed used citations, or a hash
mismatch blocks publication rather than guessing.

If a revised transcript arrives after publication, the published article and
its original evidence remain unchanged. The editor receives one high-priority
review showing the old and current artifacts and affected citations, and may
either confirm the article against the current recording or use the correction
workflow.

### Reliability, security, and release evidence

- Startup reconciles immutable transcript files with database rows and reports
  orphaned, missing, or mismatched evidence without relabeling it as valid.
- Reporting agents receive bounded reporting tools; source text remains
  evidence rather than executable instructions.
- Guarded HTTP requests fail closed if the protected transport is unavailable.
- PostgreSQL integration tests use uniquely named disposable databases and CI
  discovers database-capable tests through their import graph.
- Test code is typechecked, GitHub Actions are pinned to immutable commits, and
  the lint ceiling is lower and explicit.
- Fraunces and Source Serif 4 OFL texts and attributions ship with the Windows
  package.
