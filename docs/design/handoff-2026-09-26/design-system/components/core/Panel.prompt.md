A desk container for rail blocks (Follow-ups, The wire), the Dark Desk block and emphasis panels (Tonight’s edition, Daily scan).

```jsx
<Panel title="Tonight’s edition" meta="Each story needs every check" emphasis>…</Panel>
<Panel title="Dark Desk" meta="Never prints on its own" dark>…</Panel>
```

**Props and rules**
- `title`, `meta`
- `emphasis`: 2px yellow border, for the one thing to act on now
- `stateColor`: a 4px left edge (for example `var(--danger)`)
- `dark`: the Dark Desk block fill
