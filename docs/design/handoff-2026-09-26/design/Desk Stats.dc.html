What we never collect No cookies, no accounts, no IP addresses stored, no fingerprinting, no cross-day identifiers. A reader can’t be followed from one visit to the next, so “returning readers” is not a number we can know. Location comes from a city-level lookup that is thrown away immediately. How it’s counted. Page loads and per-story totals come from today’s counter (one count per page per day, no identity). Visits, reading time, scroll depth, live readers, sources and location need a new beacon: a ping every 15 seconds that carries only the page, the referrer site and a coarse location, with no identifier.
